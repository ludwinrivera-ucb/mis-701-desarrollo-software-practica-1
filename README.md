# Evaluación práctica Semana 1 - Desarrollo de una página web y uso de GIT

**Apertura**: sábado, 22 de agosto de 2026, 00:00.

**Cierre**: domingo, 6 de septiembre de 2026, 23:59

Crear en GitHub un nuevo repositorio **público** y enlazarlo a una carpeta en su equipo local para el desarrollo de una página web utilizando HTML y CSS.

Elegir un tema de su elección y desarrollar una página web que tengan al menos 6 páginas:

1. La página de Login
2. La página de inicio del sistema tras el login, con un dashboard
3. Una página para ver un conjunto de registros como ser la lista de productos (dependiendo de su tema)
4. Una página con un formulario para registrar información para la página anterior (ejemplo registrar producto)
5. Una segunda página para ver el registro de productos, que estén enlazados a los primeros (por ejemplo las ventas de productos)
6. Una seguna página con un formulario para registrar información

**PRESENTAR LO SIGUIENTE**

1. Una carpeta comprimida con el código fuente
2. El enlace a su repositorio de GitHub público para revision de su trabajo con GIT
    1. El repositorio en GitHub debe tener al menos 3 ramas (master, develop, feature/XXX), pueden ser más
    2. Debe tener al menos 10 commits en total entre todas las ramas
    3. Debe haber realizado al menos 1 Pull Request en Github
3. Un video de máximo 2 minutos mostrando su página web
    1. Debe mostrar las páginas de Login, el dashboard, las dos páginas de visualización de datos y las dos páginas de formularios
    2. Debe explicar el tema del trabajo y como hizo la página
    
El trabajo corresponde a 15 puntos de la maestría
